# Historique des versions

## 0.1.0
- Première version : tuiles S et M, double halo session et semaine, six états adaptatifs, rythme des 60 dernières minutes avec estimation de l'heure de la limite, mode démo, mode hors ligne, interface en français et en anglais selon la langue de Windows.
- Relais pour GitHub Codespaces : ligne d'état Claude Code et serveur local sur le port 4747, avec scripts d'installation et de désinstallation.
- Guide d'installation complet dans `docs/INSTALLATION.md`.
