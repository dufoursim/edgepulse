# Historique des versions · Changelog

## 0.1.1

**Français**
- Le widget est dessiné à sa taille réelle, puis réduit proportionnellement : l'aperçu d'iCUE est maintenant identique à l'écran du XENEON EDGE, sans texte qui déborde.

**English**
- The widget is drawn at its real size, then scaled proportionally: the iCUE preview now matches the XENEON EDGE screen, with no overflowing text.

## 0.1.0

**Français**
- Première version : tuiles S et M, double halo session et semaine, six états adaptatifs, rythme des 60 dernières minutes avec estimation de l'heure de la limite, mode démo, mode hors ligne, interface en français et en anglais selon la langue de Windows.
- Relais pour GitHub Codespaces : ligne d'état Claude Code et serveur local sur le port 4747, avec scripts d'installation et de désinstallation en français et en anglais.
- Guide d'installation complet en français et en anglais.

**English**
- First release: S and M tiles, double session and week halo, six adaptive states, 60 minute pace with estimated limit time, demo mode, offline mode, French and English interface based on the Windows language.
- Relay for GitHub Codespaces: Claude Code status line and local server on port 4747, with install and uninstall scripts in French and English.
- Complete installation guide in French and English.
